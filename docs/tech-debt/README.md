# Tech Debt

Accepted shortcuts and deferred cleanup tracked here. Each record explains
what was deferred, why, and what the resolution looks like.

When a tech debt item is resolved, move it to `archive/YYYY-MM-DD-<slug>.md`.

## Template

```markdown
# <Short Title>

**Created:** YYYY-MM-DD
**Module:** <affected module or area>

## What

What shortcut was taken or what is deferred.

## Why

Why this was acceptable at the time.

## Resolution

What resolving this looks like (scope, effort, dependencies).
```
